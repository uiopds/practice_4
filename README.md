# Практическая работа : Навигация и жизненный цикл

Мобильное приложение **SmartCalc** на фреймворке Flutter.

## Реализованный функционал:
* **Навигация:** нижняя панель `BottomNavigationBar` для переключения между тремя модулями (Калькулятор, Скидки и налоги, Конвертер величин).
* **Жизненный цикл:** перехват системных состояний приложения (`resumed`, `paused`, `inactive`) через миксин `WidgetsBindingObserver`.
* **Постоянное хранилище:** сохранение активного экрана и пользовательских настроек с помощью плагина `SharedPreferences`.
* **Сборка:** подготовка оптимизированного релизного дистрибутива `app-release.apk` (пакет `ru.uiopds.smartcalc`).
