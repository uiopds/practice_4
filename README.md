# shadrinkalk

Учебное мобильное приложение-калькулятор, разработанное на **Flutter** в рамках практической работы №4.

## Основной функционал

- **Калькулятор** — выполнение базовых арифметических операций (`+`, `-`, `×`, `÷`, `%`), работа с дробными числами, посимвольное удаление (`⌫`) и сброс (`C`).
- **Расчёт скидок** — вычисление итоговой стоимости товара и суммы экономии с помощью интерактивного ползунка (`Slider`).
- **Конвертер величин** — перевод единиц длины (м, км, см), массы (кг, г, т) и температуры (°C, °F, K) с переключателем категорий (`SegmentedButton`).
- **Светлая и тёмная темы** — мгновенное переключение оформления (`ThemeMode.light` / `ThemeMode.dark`, Material 3) по кнопке в шапке приложения.
- **Сохранение состояния** — запоминание выбранной темы и последней открытой вкладки в памяти устройства через `shared_preferences`, а также отслеживание жизненного цикла приложения (`WidgetsBindingObserver`).

## Стек технологий

- **Язык:** Dart
- **Фреймворк:** Flutter (Material 3)
- **Хранение настроек:** `shared_preferences`
