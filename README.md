# Практическая работа №4: Навигация и жизненный цикл

Выполнены все три уровня задания:
* **Базовый и повышенный:** список из трёх книг, передача названия через конструктор на `DetailPage`, возврат статуса «Прочитано» через `Navigator.pop`.
* **Творческий:** добавлены выводы `print` в `initState` и `dispose` обоих экранов, подключён `WidgetsBindingObserver`.

## Порядок сообщений в консоли:

1. **При запуске приложения:**
   `--> HomePage: initState (Главный экран создан)`
2. **При нажатии на книгу (`Navigator.push`):**
   `----> DetailPage (Книга 1...): initState (Второй экран создан)`
   *(Экран `HomePage` не удаляется, остаётся в стопке под новым экраном, его `dispose` не вызывается).*
3. **При возврате назад (`Navigator.pop`):**
   `----> DetailPage (Книга 1...): dispose (Второй экран удалён)`
   *(Верхний экран снят со стопки, у `HomePage` обновляется состояние через `setState`).*
4. **При сворачивании и разворачивании окна:**
   * Сворачивание: `inactive` -> `hidden` -> `paused`
   * Разворачивание: `hidden` -> `inactive` -> `resumed`
